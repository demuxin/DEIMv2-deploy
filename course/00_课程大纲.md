# DEIMv2 从零到源码：24 课完整课程

每一课以后都固定采用同一套学习方式：

**直觉 → 数学 → 网络结构图 → 官方源码 → 逐行解释 → Tensor shape → PyTorch 最小实验 → 回到 DEIMv2 → 本课练习。**

也就是说，我们不会出现“知道 attention 是什么，但打开源码还是看不懂”的情况。

## 第一阶段：先获得读懂 DEIMv2 所需的全部基础

### 第 1 课：从一张图片到目标检测——先建立整套地图

这是零基础真正的第一课。

先不碰复杂 Transformer，而是回答最重要的问题：

```
[B, 3, 640, 640]
        ↓
     Backbone
        ↓
feature maps
        ↓
     Encoder
        ↓
multi-scale features
        ↓
     Decoder
        ↓
300 object queries
        ↓
class + bbox
        ↓
最终检测结果
```

会学习 image、pixel、channel、feature map、stride、receptive field、bounding box、classification、localization、backbone/neck/head/encoder/decoder 分别是什么意思。

第一次进入真实入口：

```
# train.py
cfg = YAMLConfig(...)
solver = TASKS[cfg.yaml_cfg['task']](cfg)
solver.fit()
```

然后追踪到 DEIM：

```
x = self.backbone(x)
x = self.encoder(x)
x = self.decoder(x, targets)
```

官方 DEIM 的模型容器本身实际上非常简单，真正的复杂度藏在三个模块里面。

 **实验：** 自己写一个 20 行的 TinyDetector，并用 hook 打印每一层 shape。

# 有一个教学原则我建议固定下来

以后我不会直接给你贴几百行源码然后逐字翻译。

比如遇到：

```
memory, spatial_shapes = self._get_encoder_input(feats)
```

我们会按照：

1. memory 是什么？
2. 为什么需要它？
3. 输入 shape 是什么？
4. 这一行之前的数据长什么样？
5. 这一行做了哪些 reshape/flatten/cat？
6. 数学上等价于什么？
7. 输出 shape 是什么？
8. 下一层为什么需要这种 shape？
9. 用 10 行 PyTorch 单独复现
10. 再回到官方源码

这样的方式学习。

这样等课程进行到第 22 课的时候，你看到：

```
[B, 8400, 256]
```

不会只是记住这个数字，而会马上知道：

```
8400=80×80+40×40+20×20=6400+1600+400
```

也知道这 8400 个 spatial positions 从哪里来、为什么要 flatten、怎样与 300 queries 交互。

# 这个大纲还应该保留一个“动态补课”机制

因为目标是 **熟悉仓库所有重要内容** ，所以后面正式学习时，如果我们进入某个文件发现它依赖一个初学者尚未掌握的知识，例如 `inverse_sigmoid`、bilinear sampling、distribution regression、denoising queries、positional encoding、IoU/GIoU、EMA 等，我会在当课插入一个  **基础补充章节** ，而不是一句“这个不重要先跳过”。

因此 24 课是 **主课程骨架** ，不是限制内容上限。

以当前官方仓库来看，我认为这个版本已经覆盖了你要求的四个层面： **视觉基础 → DETR/D-FINE 基础 → 两个重点 X 模型源码 → DEIMv2 训练/工程全框架** 。官方仓库本身也明确建立在 D-FINE、RT-DETR、DEIM、DINOv3 等工作之上，所以按照这条依赖链学习，比直接从 `deimv2_dinov3_x_coco.yml` 硬啃有效得多。
